# Recetario colaborativo

Este proyecto contiene recetas creadas por el equipo.

## Recetas disponibles

- Tacos al pastor
- Pasta

## Cómo colaborar

1. Crear una rama nueva.
2. Hacer cambios.
3. Crear commits claros.
4. Subir la rama a GitHub.
5. Abrir un Pull Request.
6. Pedir revisión a otra persona.
